# 🚀 Minha Jornada com PHP Orientado a Objetos

Este repositório foi criado para documentar meus estudos, registrar minha evolução e armazenar todos os códigos, desafios e projetos práticos que desenvolverei ao longo da leitura do livro **PHP: Programando com Orientação a Objetos 2ª Edição**.

## 🎯 Objetivo
O foco principal é dominar os conceitos de POO aplicados ao PHP, incluindo:
* Classes, objetos, atributos e métodos
* Pilares da POO (Herança, Polimorfismo, Encapsulamento e Abstração)
* Design Patterns (Padrões de Projeto)
* Persistência de dados e boas práticas de arquitetura

## 📚 Referência Bibliográfica
Os estudos e códigos contidos aqui são baseados na seguinte obra:

> DALL'OGLIO, Pablo. *PHP: programando com orientação a objetos*. 2. ed. São Paulo: Novatec, 2009. 574 p.
